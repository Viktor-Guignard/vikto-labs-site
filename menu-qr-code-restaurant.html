Menu QR code

Menu QR code pour restaurant : une carte que vous modifiez vous-même

Vos clients scannent le QR code posé sur la table et consultent votre carte sur leur téléphone. Quand un plat est épuisé ou qu'un prix change, vous le modifiez en quelques secondes : le QR code reste le même, et votre site suit automatiquement.

Pourquoi passer au menu QR code ?

Une carte papier se réimprime à chaque changement de prix, de plat ou de saison. Entre deux impressions, elle affiche parfois ce qui n'existe plus : la burrata terminée à midi, le vin qui n'est plus en cave. Un menu QR code règle ce décalage : vos clients lisent toujours la version que vous venez d'enregistrer.

  • Toujours à jour. Un prix corrigé, un plat retiré, une suggestion ajoutée sont visibles aussitôt.
  • Lisible sur téléphone. La carte s'adapte à l'écran, sans zoomer ni télécharger de PDF.
  • Toutes vos cartes. Menu, vins, desserts, version anglaise : elles sont toutes comprises.
  • Moins de réimpressions. Vos QR codes s'impriment une fois, pour vos tables, votre comptoir ou votre vitrine.

Un QR code qui ne change jamais

Le QR code ne contient pas votre carte : il contient l'adresse de votre menu en ligne. C'est pour cela qu'il reste identique, quoi que vous changiez ensuite. Vos chevalets, autocollants et affiches restent valables ; seul le contenu du menu évolue.

Aucune application n'est à installer : l'appareil photo d'un smartphone récent suffit pour ouvrir la carte.

Comment ça se passe

  1. Nous mettons en place vos cartes. Nous les créons, ou reprenons celles que vous avez déjà (PDF, Word ou papier), dans votre espace de gestion.
  2. Vous recevez votre QR code. Il pointe vers votre menu en ligne, à placer sur vos tables, votre comptoir ou votre vitrine.
  3. Vous modifiez quand vous voulez. Plats, descriptions, prix, catégories : vous changez tout vous-même, sans limite.
  4. Tout reste synchronisé. Chaque modification est visible depuis le QR code et sur votre site, en même temps.

Ce que vous pouvez modifier vous-même

  • les plats et leurs descriptions ;
  • les prix ;
  • les catégories et l'ordre des plats ;
  • la disponibilité : un produit épuisé se masque en un clic, et réapparaît quand il revient ;
  • vos différentes cartes : menu du midi, vins, desserts, version anglaise.

L'espace de gestion est pensé pour être simple, sans compétence technique particulière. Vous pouvez essayer la même expérience dans notre démonstration en ligne.

Ce qu'un menu QR code ne remplace pas

Certains clients préfèrent une carte en main, et c'est normal. Beaucoup d'établissements gardent quelques cartes papier en salle et confient au QR code tout ce qui bouge : suggestions, prix, plats épuisés.

Les mentions obligatoires restent de votre ressort : prix, allergènes, informations sur l'origine des produits. Vous les publiez depuis votre espace, comme le reste de votre carte.
